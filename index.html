How to use this resource

Coordinates are J2000. The listed comparison-star magnitudes are catalogue values used to define the local sequences in the cited studies. The interactive finding charts use CDS Aladin Lite and a DSS2 colour background. For reproducible photometry, consult the cited paper for the reduction, aperture, quality-control, and variability-test details relevant to each field.

AGN Reference Fields · maintained as a lightweight reproducibility resource for optical monitoring. Aladin Lite imagery is served by CDS; catalogue photometry is credited per field.
